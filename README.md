- **Filterable Showcase Grid**: Dynamic filtering across Mobile (iOS/Android), Backend & Cloud, and Open Source Libraries.

## 🛠️ Local Development

To run the site locally:

```bash
# Clone the repository
git clone git@github-second:niralipm1/niralipm1.github.io.git
cd niralipm1.github.io

# Serve with any static HTTP server (e.g. Python)
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080) in your browser.
